# 사문 개수 세기 유형 파훼법 v1

`2026-09-09 · 대상: 우뢰 · 기준: 2015 개정 교과서 + 평가원 관례 · 9평 9번 공식 정답 미확인(§10)`
`위첨자(ᴬ ᴮ ᶜ ᴰ ᴱ ᶠ ᴾ ᵅ ˢ ᵃ ⁼) = 펜으로 명사 위에 쓰는 글자. 손글씨는 그냥 작은 대문자로.`

## 1. 철학 + 절차

**한 줄: 분류하지 말고 글자를 찍어라 → 글자를 더하고 빼라 → 정답이 하나인지 세라.**

- 지도는 머릿속에 고정. 종이에 벤다이어그램을 그리지 않는다. 명사 위에 코드 한 글자.
- 선지 = 범주가 아니라 코드의 합·차. 공통 문자를 소거하면 검산 범위가 줄어든다.
- 마지막 15초 = O 개수 세기. 1개가 아니면 동시 O 선지의 공통 칸이 ±1 틀린 것.

목표 120초(아래 표 합계) · 절대 상한 180초(초과 → ★ 찍고 다음 문항). 밑줄형 목표 90 · 인물 행렬형 150.

| 초 | 눈 | 펜이 하는 동작 |
|---|---|---|
| 0–8 | 발문 | 모드 단어에 ○. `적혀 있는·제시된·나타난`=전수 / `㉠~㉧`=밑줄 / `갑의·소속·속한·내집단·외집단·준거·거쳐 온·공통으로`=인물 / `옳지 않은`=□ 치고 여백에 **X1** |
| 8–20 | 선지 ①~⑤ | 선지 옆에 차식+목표값. `③ A+E=3?` `④ D=E?` `⑤ CDFPα−E=1?` `② ˢ−ᵃ=3?` `① ⚡갑·병?`. **선지에 없는 층은 OFF**(지위·⚡·소속) |
| 20–75 | 본문 1회 통독 | 집단·기관 명사구 위에 코드 1글자. 재언급 `⁼`. 지위 명사 위 `ˢ/ᵃ`(지위층 ON일 때만). 겹침·고민 문장 여백 `⚡?`. 상태어 옆 `◐(졸업·탈퇴) △(지원·목표) ★(준거) ⊘(소속감 없음) ∅(없다)`. 문장 끝마다 "이 문장 코드 몇 개?" |

| 115–120 | OMR | 마킹. 미해결 → ★ + 확정 X 지우고 남은 것 |

**우뢰 원안(벤 영역 기호화 A~E·α)에서 달라진 것**

| 전수형만 | 전수·밑줄·인물 행렬·옳지 않은 것 4모드 | 발문 문언으로 도구를 바꿈 |
| 모호한 분류는 그때그때 판단 | 모호 칸 목록(§10.2) + "그 선지를 의심" 규칙 | 시험장에서 고민하지 않고 흡수 |

## 2. 원형 코드표 (고정 지도)

```
                 [위 = 비공식적 사회화 기관]
  F 가족  P 또래  α 매체      ┌──────────────┬─────┬────────────────┐
  (공동사회·1차 / 집단 아님)  │   A 직장      │  B  │  C 외부 친목    │
                              │              │     │  D 사내 비공식  │
                              │  공식 조직 ──┼─────┼── 자발적 결사체 │
  ────────────────────────────┼──────────────┼─────┼────────────────┤
        [아래 = 공식적 기관]   │   E 학교      │  ✗  │       ✗        │ ← 출제 X
                              └──────────────┴─────┴────────────────┘
                               ←──────  이익 사회 = A B C D E  ──────→
```

|---|---|---|---|---|---|---|---|---|

| **∅** | 안 셈 | 사회적 범주·군중(관객·승객)·사건·활동·사물·존재 부정('배구부가 없어')·암시 개체 | | | | | | |

**1초 판정 — 반드시 이 순서** (끝말·키워드 규칙 대신 이것만):
1. 어미가 조합·단체·협회·연맹·정당 → **B**
2. 현재 같은 공식 조직 안의 구성원끼리 만든 친목 모임 → **D** (퇴사·졸업 후 동기 모임은 C)
3. 지역·온라인·불특정 사람들의 모임 → **C**
4. 나머지 공식 조직: 설립 목적이 교육·훈련(사회화)이면 **E**, 아니면 **A**
5. 명사 '가족·친척' → **F** · 또래·친구들 → **P** · 매체 + 이용 서술 → **α**
6. 두 역할 기대가 겹치나 → ⚡ (§5.2)

**출제 X 영역**: 자결∩공식적 기관(아래 자결 칸) · 공동사회∩공식조직 · 비공식조직∩공식조직(정의상 ∅). 여기 걸린 선지 = 무조건 X.

**모호 칸** (선지가 여기서 갈리면 그 선지 의심 → §6으로 흡수): C의 공식성(기본 X) · 종교 단체 · 군대·교도소(공식 조직·재사회화·비자발적, 공식적/비공식적 기관 여부 교과서별) · 연수원(회사와 별개?) · 학생 동아리 D · 부서 · 마을(1차적 기관?) · 1차/2차 집단에서 C·D 위치 · 또래=공동사회. 전체 목록 §10.2.

## 3. 선지 공식표

**범주 = 코드 합**

| 범주 | 코드 |
|---|---|
| 사회 집단 | A+B+C+D+E+F+P |
| 이익 사회 | A+B+C+D+E |
| 공동 사회 | F (+N) [P 모호] |
| 공식 조직 | A+B+E |
| 자발적 결사체 | B+C+D |
| 비공식 조직 | D |
| 공식적 사회화 기관 | E |
| 비공식적 사회화 기관 | A+B+C+D+F+P+α = **전체 − E** |
| 1차 집단 | F+P (C·D 모호) |
| 2차 집단 | A+B+E (C·D 모호) |
| 1차적 사회화 기관 | F+P |
| 2차적 사회화 기관 | A+B+C+D+E+α |

**차식 = 공통 문자 소거** (소거된 칸은 잘못 세도 결과 불변 → 검산 범위 축소)

| 선지 형태 | 소거 후 |
|---|---|
| 이익 − 자결 | A+E |
| 이익 − 공식조직 | C+D |
| 이익 − 비공식조직 | A+B+C+E |
| 공식조직 − 자결 | A+E−C−D |
| 자결 − 비공식조직 | B+C |
| 공식조직 − 공식적기관 | A+B |
| 비공식적기관 − 공식조직 | C+D+F+P+α−E |
| 비공식적기관 − 공식적기관 | A+B+C+D+F+P+α−E |
| 비공식적기관 − 자결 | A+F+P+α |
| 공식적기관 vs 비공식조직 | E vs D |
| 공동 vs 공식조직 | F vs A+B+E |
| 사회집단 − 이익 | F+P |

**포함 관계**
- D ⊂ B+C+D ⊂ A+B+C+D+E (비공식 조직 ⊂ 자결 ⊂ 이익)
- E ⊂ A+B+E ⊂ A+B+C+D+E (공식적 기관 ⊂ 공식 조직 ⊂ 이익)
- B = 공식조직 ∩ 자결
- D∩공식조직 = ∅ · E∩자결 = ∅ · (F+P)∩이익 = ∅ · α∩집단 = ∅
- 항등식: **이익 = 공식조직 + 자결 − B** · **비공식적 기관 = 전체 − E**
- 단조: D ≤ 자결 ≤ 이익 · E ≤ 공식조직 ≤ 이익 → 위반 선지 즉시 X

## 4. 개체 추출 규칙

### 4.1 세는 것 (전수 모드)
1. 집단·기관을 지칭하는 **명사구 전체에 코드 1개**. 개체 구분은 고유 표지(○○·△△·◇◇) 단위.
2. 소속·시제 무관: 진학 목표 학과·지원한 회사·졸업한 학교·탈퇴한 단체도 '적혀 있으면' 셈. `[모호 — 9번 수의학과 역산 관례. 인물 모드에선 즉시 OFF]`
3. 학교형 중첩: ○○고등학교 / 사범대학 / 수의학과 = 각 1(명칭·기관 다름). '□□대학교 △△학과' 한 덩어리 = 1 `[모호]`.
4. 매체: 이용 서술 있는 매체 명사 낱개(서적·영화·TV·인터넷 각 1).
5. 가족·또래·마을: 명사가 적혀 있을 때만.

### 4.2 안 세는 것
1. **암시 개체**: 남편→가족, 진학→대학생, 재직→교사, 조카→이모. '적혀 있는' = 명사 존재 기준.
2. 사건·활동·사물·동물: 시합·약속·관람·입양·유기묘·입시 정보·강연.
3. **수식어 속 명사** `[모호 — 작업 규칙, §10.2-14]`: ○○고등학교 **동창회**(C 1, E 0) · 영화 감상 **카페**(C, α 0) · **신문**사(A, α 0) · 시청 공무원 **노동조합**(B; A는 '시청'이 따로 적혔을 때만).
4. **재언급**: 원내=병원, 교내=고등학교, 그 단체·노조·모교·학교·대학·직장·이 동아리 → `⁼`, 0개. 기준 = 지시 대상, 명칭 아님. 표지 다르면(△△고 vs ◇◇고) 별개.
5. 부서·시설: 내과·총무과·인사과 = 모호(기본 ⁼ 처리). 연수원 모호.
6. 사회적 범주·군중: 청소년들·노년층·수험생들·관객·승객.
7. 존재 부정: '배구부가 없어' ∅. '가입하려 했으나 못함' → 개체는 적혀 있으니 전수 모드 셈, 인물 모드 ×.

| 발문·선지 문언 | 모드 | 도구 |
|---|---|---|
| 자료에 적혀 있는 / 제시된 / 나타난 | 전수 | 집계 한 줄 |
| 밑줄 친 ㉠~㉧ | 밑줄 | ㉠~㉧에만 코드. 나머지 명사 손대지 않음 |
| 갑의 / 갑이 + 소속·속한·가입·내집단·외집단·준거·거쳐 온·다니는·근무하는·공통으로 속한 | 인물 | 인물×집단 행렬 |
| 갑~병의 지위 / 갑이 가진 지위 | 인물(지위) | 이름 옆 사람별 열거. 타인 지위 제외 |
| 옳지 않은 것 | 검산 반전 | 목표 = **X 정확히 1개** |

혼합 선지("적혀 있는 비공식 조직 개수 = 갑의 외집단 중 자결 개수") → 좌변 전수, 우변 행렬. **이때만 선지를 다시 읽는다.**

### 4.4 인물 행렬
행 = 인물 / 열 = 코드 붙은 개체.
칸: `○` 현재 소속 · `◐` 과거(졸업·탈퇴·퇴사·그만둠) · `△` 지원·목표·정보만 · `★` 준거(동경·기준으로 삼음·본받음·목표) · `⊘` 소속이나 소속감 없음(겉돈다·이질감) · `×` 비소속.
- 내집단 = ○. 외집단 = ×·◐·△ (○이 아닌 집단). `⊘` = 내집단 X, 외집단도 모호 → 그 선지 의심.
- 준거 집단 = ★(소속 무관). 소속 집단이 준거인 경우(자부심·긍지·규범을 기준으로) = ○★.
- 거쳐 온 = ○+◐. 공통으로 속한 = 두 행 모두 ○.
- 상태 변화 동사(탈퇴·졸업·그만둠·아직 가입 안 함·소속감을 느끼지 못함) 보이는 즉시 기호 수정.
- 예기 사회화 신호 = △★(진학·입사 목표 집단).

### 4.5 지위 계수 방식
- 인물 한정("갑~병의 지위"): **사람별 열거만**. 타인 지위 명사(시어머니·학부모·다른 교사) 제외.
- 전수("자료에 적혀 있는 지위"): 명사 단위(타인 지위 포함). `[모호 — 9번 ②는 어느 독법이든 X라 미검증]`
- 지위 **종류** 단위: 같은 지위 여러 사람 = 1.
- 시험장: 사람별로 먼저 세고, 전수 발문이면 타인 지위를 괄호로 병기 `ˢ1(3)`. 선지가 두 값 사이에서 갈리면 §6.

## 6. 정합성 검산

전제: 옳은 것 → O 정확히 1개. 옳지 않은 것 → X 정확히 1개.

```
O 개수
 =1 → 마킹
 ≥2 → 동시 O 선지의 차식에서 공통 칸 → 그 칸이 ±1 틀림
      순서 ① 중복(같은 대상 다른 이름: 모교=대학교, 갑의 병원=병원)
           ② 오분류(…원/…과 끝말 · 조합 접두어 · 수식어 속 명사 · C/D)
           ③ 누락(문장 끝 재스캔: 지위 구절 속 기관 · 소속 아닌 기관 · 두 번째 학교)
      공통 칸 없음(층이 다름: 지위식 vs 집단식) → 각 층에서 모호 항목(§10.2)이 걸린 선지를 의심,
           확정 규칙만으로 X인 쪽을 지운다
 =0 → ① 오분류 후보 재확인(위 ②)
      ② ⚡ 재확인(겹쳐·같은 날 구조가 있는데 ✗로 닫았나 · 관계 명사에서 지위 복원했나)
      ③ 모호 개체 되살리기: α(이용 서술 없이 언급만 된 매체 → 임시 계수) → F(관계 명사만 있는 가족)
           → 학과·단과대 분리 → B 공식성
반복 1회. 실패 → 확정 X 지우고 남은 것 마킹 + ★.
```

**선지 숫자 역산**: 오답 선지의 숫자 = 출제자가 예상한 실수의 결과값. 차식에 넣어 "어느 칸이 몇이면 이 숫자가 나오나"를 역산 → 함정 위치. 오답 여러 개가 같은 칸을 가리키면 그 칸이 출제자의 함정(9번: ③④ → E). 단, 함정 방향은 누락·중복·오분류 셋 다 가능 — **유일성은 방향을 알려주지 않는다.**

**주의**: 유일성은 오라클이 아니다. 오분류 세계에서도 O가 1개면 침묵한다(드릴 1의 끝말 세계). 분류 규칙이 먼저, 유일성은 타이브레이커.

### 7.2 정답이 갈리는 변수

| 선지 | 참 조건 |
|---|---|
| ① | r=1 |
| ② | y=1 (ˢ4−ᵃ1=3) |
| ③ | x=0 (A+E=1+2=3) |
| ④ | x=0 (D2=E2) |
| ⑤ | u=1: **z+w=x** / u=0: z+w=x−1 |
