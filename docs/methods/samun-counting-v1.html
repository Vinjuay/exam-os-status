4. 개체 추출 규칙

4.1 세는 것 (전수 모드)

  1. 집단·기관을 지칭하는 명사구 전체에 코드 1개. 개체 구분은 고유 표지(○○·△△·◇◇) 단위.
  2. 소속·시제 무관: 진학 목표 학과·지원한 회사·졸업한 학교·탈퇴한 단체도 '적혀 있으면' 셈. [모호 — 9번 수의학과 역산 관례. 인물 모드에선 즉시 OFF]
  3. 학교형 중첩: ○○고등학교 / 사범대학 / 수의학과 = 각 1(명칭·기관 다름). '□□대학교 △△학과' 한 덩어리 = 1 [모호].
  4. 매체: 이용 서술 있는 매체 명사 낱개(서적·영화·TV·인터넷 각 1).
  5. 가족·또래·마을: 명사가 적혀 있을 때만.

4.2 안 세는 것

  1. 암시 개체: 남편→가족, 진학→대학생, 재직→교사, 조카→이모. '적혀 있는' = 명사 존재 기준.
  2. 사건·활동·사물·동물: 시합·약속·관람·입양·유기묘·입시 정보·강연.
  3. 수식어 속 명사 [모호 — 작업 규칙, §10.2-14]: ○○고등학교 동창회(C 1, E 0) · 영화 감상 카페(C, α 0) · 신문사(A, α 0) · 시청 공무원 노동조합(B; A는 '시청'이 따로 적혔을 때만).
  4. 재언급: 원내=병원, 교내=고등학교, 그 단체·노조·모교·학교·대학·직장·이 동아리 → ⁼, 0개. 기준 = 지시 대상, 명칭 아님. 표지 다르면(△△고 vs ◇◇고) 별개.
  5. 부서·시설: 내과·총무과·인사과 = 모호(기본 ⁼ 처리). 연수원 모호.
  6. 사회적 범주·군중: 청소년들·노년층·수험생들·관객·승객.
  7. 존재 부정: '배구부가 없어' ∅. '가입하려 했으나 못함' → 개체는 적혀 있으니 전수 모드 셈, 인물 모드 ×.
