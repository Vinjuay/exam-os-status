## 참고한 대시보드 패턴

인기 유료 노션 대시보드(Student OS · Janice Studies 대시보드 · Thomas Frank 계열 Home)와 노션 디자인 가이드에서 공통으로 쓰는 것만 골랐다.

| 패턴 | 홈에 적용한 것 |
|---|---|
| 첫 화면 = 「오늘」 | 🎯 지금 교시 바로 아래 📅 오늘 할 일(오늘 날짜만, 교시 순) |
| 할 일은 한 곳에 | 대기함 활성 줄을 홈 「✅ 해야 할 일」로 — 동기화 블록이라 대기함 페이지와 같은 내용 |
| 한 줄 제목 + 접힌 설명 | 항목마다 굵은 제목 · 회색 답 형식·마감 한 줄, 원문 전체는 「자세히」 토글 |
| 빈 칸 숨기기 | 「지금 여기 남은 일 없습니다」 소제목 삭제 · 이번 주는 토글 제목 안으로 |
| 콜아웃으로 영역 구분 | 기록 입력(✍·📷·🃏)을 콜아웃 하나로 묶음 |
| 위계는 제목 3단계만 | `##` 오늘 · 해야 할 일 · 상태 / `###` 소제목 / 나머지는 본문 |

## 홈 순서 (위 → 아래)

1. 오늘의 문장 · 수능 날짜 (회색 인용 한 줄)
2. `[R:now]` 지금 교시
3. **📅 오늘 할 일** — DAY 보기, 필터 `오늘 = "오늘"`, 교시 순, 열 = `할 일` 하나
4. 기록 콜아웃 — ✍ 한 줄 · 📷 사진 · 🃏 Anki · 할 말 3가지
5. **✅ 해야 할 일** — 동기화 블록(대기함 활성 줄) + ACTION 「1탭으로 답하기」
6. **📊 상태** — `[R:status]` · `[R:auto]`
7. 🗓 이번 주 (접힌 토글 안에 DAY 주간 보기)
8. `[R:stamp]`
9. ⚙ 시스템 (접힌 토글 안에 HEARTBEAT 보기 — D-day · 갱신끊김 · 야간)
10. 더 보기 (기존 토글 그대로)

## 바꾼 것

- **DAY `오늘`** (수식·텍스트): 날짜가 오늘이면 「오늘」. 뷰 DSL에 상대 날짜 필터가 없어 이 속성으로 거른다. 전에는 「최신 날짜 순」이라 9/26·9/25 줄이 오늘보다 위에 떴다.
- **HEARTBEAT `D-day`** (수식): `D-` + 2026-11-19까지 남은 날. 옛 홈의 「D-60 · 오늘 2026-09-20」 콜아웃은 home.py 은퇴 뒤 갱신이 멈춰 틀린 숫자를 보이고 있었으므로 지웠다.
- **대기함**: 활성 줄은 홈의 동기화 블록 원본을 가리키는 참조 블록으로 바뀌었다. 처리됨 기록은 대기함에 그대로 남는다. 새 줄은 반드시 동기화 블록 **안에** 넣는다(대기함 상단에 AI 작성 규칙 한 단락).

## 2차 (같은 날) — 우뢰 「하트비트는 안 봐도 됨 · 표는 열 너비가 다 같아 읽기 힘듦」

- HEARTBEAT 보기를 맨 아래 「⚙ 시스템」 토글로 내렸다.
- DAY `할 일` (수식): `⬜/✅ + **시작–끝** + 과목 · 항목`을 한 칸에 담는다. 「오늘 할 일」·「이번 주」 표는 이 열만 보인다.
- API 한계: 표의 제목 열(`키`)은 숨길 수 없고, 열 너비는 API로 정할 수 없다. 갤러리·목록 보기도 API로는 제목 숨김·줄바꿈을 못 켠다(시험 후 삭제).
- 근본 해결은 render.py 몫(🤖 R12): `[R:today]` 구역에 오늘 할 일을 표가 아닌 줄 글로 쓰기 · `[R:now]`에 D-N · `[R:status]`를 한 줄로.
