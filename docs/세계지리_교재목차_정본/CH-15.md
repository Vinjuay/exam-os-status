### 생성 원리와 근거

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형** — 필기 J 첫 줄 「대지형: 산 → 평야」가 생성 원리다. 조산·습곡으로 솟은 산은 오래될수록 낮아지고 평평해진다. 그래서 가장 젊은 신생대는 높고 험하고 불안정하며, 고생대는 낮고 완만하고 안정되며, 가장 오래된 시원생대는 순상지(안정 지괴)다. 시간 순서가 곧 높이 순서의 역순이어서, 시대 하나를 떠올리면 모양·안정성·자원이 줄줄이 따라온다.

> 근거: 사진 J(c3ba3c0a) 왼쪽 메모지 — 녹색 여백 숫자와 함께 세 머리가 위→아래(왼쪽 열), 오른쪽 열 순으로 적혀 있다: 「6 시원생대 : 철 / 순상지 : 안정 지괴」 · 「5 고생대 : 석탄 … 낮 · 완만 · 안정」 · 「7 신생대 : 석유, 천연, 구리 … 높 · 험준 · 불안정」. 실측 3(직접 확대 확인). 개념망 v1 09-14 「1. 순상지,구조 평야, 탁상지 (융기) / 2. 고기산맥 5개 / 3. 신기 산맥」도 같은 세 갈래를 같은 순서로 준다.

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형 › 대지형 생성 원리** — 판이 양쪽에서 밀어붙이면(→← 그림) 지층이 휘어 솟는다(조산·습곡). 이렇게 산이 생기고, 그 산이 시간이 지나 평야가 된다. 이 한 줄이 아래 지질 시대 세 칸의 순서를 만든다. 신생대 = 막 솟은 산, 시원생대 = 다 닳은 평야.

> 근거: 사진 J 왼쪽 메모지 맨 윗줄 — 「대지형 : 산 → 평야」 + 양쪽 화살표가 가운데로 모이는 산 그림 + 「(조산, 습곡)」. 실측 3 — 조산·습곡 / 산 / 평야.

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형 › 시원생대 대지형** — 가장 오래돼 오랫동안 깎인 땅이 방패처럼 평평한 순상지(= 안정 지괴)다. 거기서 수평 지층이 그대로 들려 올라가면 탁상지(J 그림의 위쪽 화살표 = 융기), 수평 지층이 평평하게 남아 있으면 구조평야다. 셋 다 「오래됨 → 안정 → 평탄」에서 나온다. 자원은 철.

> 근거: 사진 J — 「시원생대 : 철 / 순상지 : 안정 지괴」, 녹색 탁상지 그림(겹친 아치 + 아래에서 위로 화살표) 위 빨간 「탁상지」, 평평한 빨간 선 위 「구조평야」. 개념망 v1 09-14 「1. 순상지,구조 평야, 탁상지 (융기)」. 실측 3이 두 원전에서 일치한다.

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형 › 시원생대 대지형 › 순상지 6곳** — 이승헌이 준 생성 원리는 「머릿속으로 지도를 그리면서」다. 유럽에서 출발해 동쪽(시베리아)으로 가고, 태평양을 건너 북미로 간 다음, 아래로 내려오며 아프리카 → 호주 → 브라질을 한 번에 훑는다. 순서가 곧 검산 장치다.

> 근거: 사진 J 「시원생대」 앞 녹색 여백 숫자 「6」(직접 확대 — 긴 세로획 끝이 말린 6). 개념망 v1 09-14 「6개 ( 외우는 법 머리 속으로 지도를 그리면서) 유럽부터 발트 오른쪽으로 가면서 시베리아,안가라 태평양 건너면 로렌시아 아래 쪽 내려오묜 아프리카 사하라 사막 쪽 그리고 호주와 브라질」. 두 원전의 6이 일치한다. 이름은 v1 원전이다. 기존 U-세지-03 카드(「순상지·구조평야·탁상지 □개를, 머릿속으로 지도를 그리는 순서로?」 → 6)가 이미 있다.

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형 › 고생대 — 고기 습곡 산지** — 고생대에 솟은 산은 오래 깎여 낮고 완만하며 안정되어 있다(J 「낮 · 완만 · 안정」). 자원은 석탄(고생대 식물). 고기 습곡 산지는 시원생대 안정 지괴의 가장자리에 붙어 서므로, 순상지 6곳과 같은 지도 순서(유럽 → 동쪽 → 북미 → 아프리카 → 호주)로 훑으면 다섯이 한 번에 나온다. 스칸디나비아는 발트, 우랄은 발트·안가라 사이, 애팔래치아는 로렌시아, 드라켄즈버그는 아프리카, 그레이트디바이딩은 호주에 붙어 있다.

> 근거: 개수: 사진 J 「고생대 : 석탄」 앞 녹색 여백 숫자 「5」(선명) + 개념망 v1 09-14 「2. 고기산맥 5개」. 두 원전 일치 → 원전명시 5. 이름: 어느 원전에도 없다(v1·마스터본·Anki 지형 11노트 모두 없음 — U-세지-03 미상 목록 1순위). ㉣ 필기 개수 5에 맞춰 ㉢ 수능·평가원 대지형 지도 문항에서 고기 습곡 산지로 반복해서 표시돼 온 다섯으로 채웠다. 순서는 v1 순상지 「지도 그리기」 원리를 옮겨 쓴 것이다.

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형 › 신생대 — 신기 습곡 산지** — 신생대 산은 막 솟아 높고 험하며 판 경계 위라 불안정하다(J 「높 · 험준 · 불안정」). 자원은 석유·천연가스·구리. 이 산맥들을 판의 경계 두 갈래가 그대로 가른다. 대륙과 대륙이 부딪치면 알프스-히말라야 계열, 대륙과 해양이 부딪치면 환태평양 계열이다. 그래서 7은 4 + 3 으로 나뉜다.

> 근거: 개수: 사진 J 「신생대 : 석유, 천연, 구리」 앞 녹색 여백 숫자 「7」(직접 확대 — 꺾인 7). 분해: 개념망 v1 09-14 「3. 신기 산맥 / 1. 알프스‘히말라야 4개 / 2. 환태평양 3, 3 (안데스, 로키 , 남알프스 ) ( 러시아의 호처럼 캄차카 반도,일본, 필리핀 )」. v1 은 신기 산맥을 두 계열로 나누고, J 오른쪽 장 「판의 경계」도 같은 두 갈래(알·히 / 환태평양)다. 4 + 3(안데스·로키·남알프스) = 7 이 J 의 7과 정확히 맞는다. 뒤의 3(캄차카·일본·필리핀)은 v1 스스로 「호처럼」이라 불러 산맥이 아닌 호상열도로 따로 묶었으므로 7 밖이다.

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형 › 신생대 › 알프스-히말라야 계열** — 대륙과 대륙이 부딪치는 경계(J 「알·히 대↔대」)다. 아프리카판이 유라시아판을 밀어 아틀라스·피레네·알프스가, 인도판이 밀어 히말라야가 솟았다. 서쪽에서 동쪽으로 한 줄로 이어지므로 서→동 순서가 곧 사슬이다.

> 근거: 개수: 개념망 v1 09-14 「1. 알프스‘히말라야 4개」(원전명시 4, 이름 없음 — U-세지-03 미상 목록). 사진 J 오른쪽 장 「알·히 → 대 ← 대」가 이 계열의 생성 원리(대륙↔대륙)를 준다. 이름: ㉢ 수능·평가원 세계 대지형 지도에서 알프스-히말라야 조산대로 표시돼 온 산맥으로 채웠다. 마스터본 §10 「알프스산맥 = 유라시아판과 아프리카판의 충돌」은 알프스 하나만 받친다(4순위, 구조 근거 아님).

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형 › 신생대 › 환태평양 계열** — 대륙과 해양이 부딪치는 경계(J 「환태평양 → 대 ← 해」)에서 해양판이 대륙 밑으로 들어가며 대륙 가장자리에 산맥이 선다(안데스·로키·남알프스). 해양 쪽에서는 호(弧) 모양 섬들이 늘어선다(v1 「러시아의 호처럼」 캄차카·일본·필리핀). 앞의 3이 신생대 7의 3이다.

> 근거: 개념망 v1 09-14 「2. 환태평양 3, 3 (안데스, 로키 , 남알프스 ) ( 러시아의 호처럼 캄차카 반도,일본, 필리핀 )」 — 괄호 둘로 원문이 직접 묶었다. 사진 J 오른쪽 장 「환 태평양 → 대 ← 해」. 기존 U-세지-03 카드(「신기 습곡산맥 환태평양 □+□을…」 → 3+3)가 이미 있다.

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형 › 지질 시대 × 자원** — 자원은 그 시대에 만들어진 것이 그 땅에 남는다. 시원생대의 오래된 땅에는 철, 고생대 식물이 묻힌 곳에는 석탄, 신생대 지층·습곡 구조에는 석유·천연가스가, 신생대 조산대에는 구리가 있다. 시대를 떠올리면 자원이 따라온다. 이 연결은 21 에너지 자원 장과 이어진다.

> 근거: 사진 J — 「시원생대 : 철」(녹색 큰 글씨) · 「고생대 : 석탄」 · 「신생대 : 석유, 천연, 구리」. 실측 1 + 1 + 3 = 5. 「천연」은 천연가스의 줄임.

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형 › 지질 시대 × 모양·안정성** — 「산 → 평야」의 시간 축을 거꾸로 읽은 것이다. 젊을수록 높고 험하며 판 경계 위라 불안정하다. 개수로 외울 목록이 아니라 세 시대의 속성 짝이므로 개수를 두지 않는다. 대신 지질 시대 3 카드 뒷면 둘째 줄로 싣는다.

> 근거: 사진 J — 시원생대 「순상지 : 안정 지괴」 + 평평한 선 그림 / 고생대 그림에 녹색 「낮」·「완만」·「안정」 / 신생대 그림에 녹색 「높」·「험준」, 빨간 「불안정」.

**Ⅲ 지형 › 15 세계의 대지형 › ① 지질 시대별 대지형 › 신생대 그림의 빨간 동그라미** — 신생대 산 그림에 빨간 동그라미 둘이 있다. 왼쪽 산자락 하나, 오른쪽 산자락 하나. 판독이 맞다면 구리(조산대 산지)와 석유(습곡 구조)의 자리를 표시한 것으로 보이지만, 지어낼 수 없어 이름을 비운다.

> 근거: 사진 J 왼쪽 장 하단 — 크게 확대해도 왼쪽 동그라미 안은 흐려진 「구」 비슷한 획, 오른쪽 동그라미 안은 「석」에 가까운 획이다. 판독 불확실.

**Ⅲ 지형 › 15 세계의 대지형 › ② 판의 경계** — 무엇과 무엇이 부딪치느냐가 산맥의 계열을 가른다. 대륙끼리면 충돌해 솟고(알프스-히말라야), 대륙과 해양이면 해양판이 파고들며 대륙 가장자리가 솟고 호상열도가 생긴다(환태평양). 이 두 갈래가 신생대 신기 습곡 산지 7 = 4 + 3 의 칼금이다. ②가 ①의 신생대 칸을 설명하는 원인이다.

> 근거: 사진 J 오른쪽 메모지 — 「판의 경계 [ 알·히 → 대 ← 대 / 환 태평양 → 대 ← 해 ]」. 대괄호 하나에 두 줄, 실측 2. 이 사진이 지형 PART 표지 위에서 찍혔으므로 1순위(교재 여백 필기)다.

**Ⅲ 지형 › 15 세계의 대지형 › ② 판의 경계 › 열점** — 판의 경계가 아닌 판 한가운데에서도 맨틀에서 마그마가 솟는 자리가 있다. 그 마그마는 유동성이 강한 현무암이라 방패처럼 완만한 순상화산을 만든다. 경계(②)의 예외이면서 16장 화산으로 넘어가는 다리다.

> 근거: 개념망 v1 09-14 「5. 열점」 한 줄(대지형 목록의 끝). v1 화산 「1. 순상 하와이/유동성이 강한 애가 현무암이 됨」. 필기 J 에는 열점이 없다. J 가 이 범위를 다루지 않으므로 X41 예외로 v1(3순위)을 썼다. 개수는 어느 원전에도 없다.

## 추론으로도 못 세운 자리

- ① › 지질 시대 × 모양·안정성 — 세 시대의 속성 짝이라 셀 목록이 아니다. 개수를 두지 않고 지질 시대 3 카드 뒷면 둘째 줄로 싣는다
- ① › 신생대 그림의 빨간 동그라미 2개 — 안의 글자가 「구」·「석」으로 보이나 판독 불확실. 이름도 개수도 비움
- ② › 열점 — 원전(v1 「5. 열점」)이 개수도 사례 목록도 주지 않았다. 사례 하와이는 v1 화산 절의 순상화산에서 왔다

## 이승헌에게 물으면 풀리는 것

- 15장 교재 지면(096~101)의 절 번호와 제목 — 이번에 추론한 「2절(지질 시대별 대지형 → 판의 경계)」은 관측값이 아니다. 3절(① 대지형의 형성 ② 지질 시대별 대지형 ③ 판의 경계) 가능성도 있다. 096쪽 사진 한 장이면 L2 검산값이 확정된다
- 판의 경계 개수가 두 원전에서 다르다 — 개념망 v1(09-14)은 「4. 판의 경계 3개」, 필기 J(교재 PART 표지 위)는 두 갈래(알·히 = 대↔대 / 환태평양 = 대↔해)다. 최신인 J 의 2로 카드를 냈다(X41). 확인할 것: v1 의 3이 발산·수렴·보존을 센 것인지, 아니면 대↔대·대↔해·해↔해(캄차카·일본·필리핀 호상열도)를 센 것인지. 후자라면 J 가 해↔해를 생략한 것이고 3이 맞을 수 있다
- 고기 습곡 산지 5의 이름 — 스칸디나비아·우랄·애팔래치아·드라켄즈버그·그레이트디바이딩으로 추론했다. 이승헌이 부른 다섯이 이것인지(톈산·알타이·페닌이 들어가는지) 확인해야 한다
- 알프스-히말라야 4의 이름 — 아틀라스·피레네·알프스·히말라야로 추론했다. 캅카스·자그로스·카르파티아가 대신 들어가는지 확인해야 한다
- J 의 「7 신생대」가 알프스-히말라야 4 + 환태평양 3(안데스·로키·남알프스)이 맞는가 — 환태평양 뒤의 3(캄차카·일본·필리핀)까지 넣으면 10이 되어 7과 맞지 않아 뺐다
- J 신생대 산 그림 위 빨간 동그라미 둘 안의 글자(「구」·「석」?) — 구리·석유의 산출 자리 표시인가
- 열점은 15장(대지형) 소속인가, 16장(화산) 소속인가 — v1 은 대지형 목록 끝에 두었고 교재 배치는 모른다
- 덱 쪽 파급 — 기존 `지형` 덱의 L1 목차 카드 「지형에서 묻는 갈래 □개는? → 7(대지형 → 화산 → 카르스트 → 건조 → 빙하 → 주빙하 → 해안)」은 v1 강의 순서다. 교재로는 15 대지형 / 16 화산·카르스트·해안 / 11 건조 / 13 빙하·주빙하 로 흩어진다. 카드를 폐기하지는 않되(X42), 교재 PART Ⅲ 목차 카드(「지형 PART 장 □개 → 2」)를 따로 세울지 판단이 필요하다
