### 1-3. 신규 카드 cap을 없앤 자리

cap을 그냥 지우면 신규 유입이 미래의 due로 돌아와 복습 시간이 폭증한다. 그래서 **상한이 아니라 주간 결정**으로 옮긴다 — v1.1 E3가 예제 큐에서 이미 쓴 형태 그대로다.

- 카드 신설 자체에 상한 없음.
- **그 주 Anki 신규 유입 수는 주간 계획 세션에서 우뢰가 숫자 하나로 정한다.**
- 화면에는 현재값만 표시한다 — `due N장 · ≈M분 · 17.5초/장`. 시스템은 막지 않는다.

### 1-4. 상한이 사라진 자리에 들어오는 것

상한은 **판단을 대신해 주던 장치**다. 없애면 그만큼 판단이 매주 늘어난다. 이것이 D18의 실제 비용이고, 받는 곳은 D19다.

가장 크게 비는 자리는 **기한**이다. 10/20(D-29) 신규 콘텐츠 금지선이 사라지면서 `로드맵_보완_0921.md` §6의 「216 실모 세트 확보 · 박석준 파이널 1회독 · 태도 압축어 등재를 10/20까지」가 **근거를 잃는다.** 남은 절대 기한은 **11/19 하나**다.

→ 그러므로 **잔여일 대비 진도는 주간 계획 세션이 매주 명시적으로 센다**(§2-3). 상한이 대신 세어 주던 것을 이제 사람이 센다.

고정이 사라진 만큼 세션이 받는 항목이 늘어난다. **매주 이 순서로 결정한다.**

3. **배치 형태 결정** — 숙련도 단계별로 몰기 / 병행 / 분산 (§3-4)
4. **월~금 2,930분 배분** — 과목·블록·연속 일수. 기본 제시값은 직전 주

6. **서명** — 이 5개가 그 주의 유일한 계획이다

## 3. D20 — 숙련도 판정 프로토콜 (전 과목)

### 3-1. 우뢰 판정의 요지

> 「현재는 방법론이 미숙해서 몰아하는 게 초반 숙련도를 높이는 데 좋고, 틀린 이유를 분석해서 숙련도가 어느 정도 올라 온 것 같으면 빈도를 늘리는 방향으로 하면 될 듯」

몰기와 분산은 **대립이 아니라 순서**다. 로드맵 보완 §5-2는 「몰기는 개념 학습에만, 인출은 매일」이라고 투입 종류로 갈랐는데, 우뢰 판정은 **시간축으로** 가른다 — 숙련 초기에는 몰기가 맞고, 숙련이 오르면 분산이 맞다. 두 갈래는 양립한다(§3-4 표가 둘을 합친 것이다).

### 3-2. 필수 절차 — 분석·추론 없이 묻지 않는다

**「사문 숙련도 어떠세요?」처럼 근거 없이 묻는 것은 규격 위반이다.** AI는 반드시 아래 4단계를 거친다.

**① 수집** — 그 과목·단원의 근거를 모은다.

| 재료 | 읽는 것 |
|---|---|
| ERRORLOG | 실패 코드 분포 14일 / 7일 · 단원별 · 미코딩 비율(표본 신뢰도) |
| 예제 큐 | 1차 해결 / 2차 실패 / 종결 · 표본 수 |
| 파이프라인 회수율 | 배운 방법론이 다음 문항에서 다시 나오는가 |
| Anki | 그 모듈 카드의 Again율 · 평균 초/장 · 최종접촉일 |
| 백지 인출 | L1~L5 판정 (있으면) |
| 실모 | 구간 소요 vs 배점 · 「시간」 코드 분포 (있으면) |

**② 분석** — 실패 코드를 숙련도 축으로 읽는다.

| 우세 코드 | 읽는 의미 | 추정 단계 |
|---|---|---|
| `개념` · `인출` | 재료가 아직 안 들어왔다 | **입력 이전** |
| `기준혼동` | 재료는 있으나 판정 경계가 안 선다 | **초기** |
| `미숙련` | 절차는 아는데 손이 안 따른다 | **중기** |
| `실행실수` · `시간` | 절차가 섰고 속도만 남았다 | **후기** |
| `조건오독` · `발문오독` | **숙련도 축이 아니다** — 읽기 정확도라 따로 다룬다 | (별도) |
| `구조` | 문항 구조 파악. 과목별로 다르게 읽는다(국어=지문 구조 / 수학=문제 구조) | 문맥 판단 |

**③ 추론 제시** — 결론만 던지지 않는다. **근거 → 읽은 방식 → 확증 한계 → 추정**을 한 덩어리로 낸다.

> 예시 (사회문화, 09-21 실측):
> 「탐구 최근 14일 실패는 `기준혼동` 6 · `미숙련` 5이고, 7일로 좁히면 `미숙련` 5 · `기준혼동` 1입니다. `개념`·`인출`이 0이라 **재료는 이미 들어와 있습니다.** 최근으로 올수록 `기준혼동`이 빠지고 `미숙련`만 남는 것은 **판정 경계는 서기 시작했고 손이 아직 안 따른다**는 쪽으로 읽힙니다. 다만 예제 2차 표본이 0이라 확증은 못 하고, 탐구 64행 중 미코딩은 1행뿐이라 표본 자체는 믿을 만합니다.
> **그래서 사회문화 숙련도는 「초기→중기 경계 — 몰기로 절차를 세우는 단계는 거의 지났고, 이제 빈도가 약이다」로 추정합니다.** 맞습니까?」

**④ 우뢰 답 → 배치 전환.** 우뢰 답이 AI 추정과 다르면 **우뢰 답이 상위**다. 추정과 답이 어긋난 건은 기록에 남겨 다음 판정을 보정한다(어긋남이 반복되면 ②의 읽는 방식이 틀린 것이다).

### 3-3. 언제 묻는가

- **주간 계획 세션(토 18:30)에서 과목별 1회** — 국어 · 수학 · 영어 · 세계지리 · 사회문화 전부.
- 그 사이라도 **실패 코드 분포가 단계를 넘어 보이면 즉시** 제시한다(예: `기준혼동` 우세였던 과목에서 `실행실수`가 1위로 올라온 때).
- 표본이 없으면 **없다고 말한다.** 「표본 0이라 판정 불가 — 이번 주는 직전 단계를 유지합니다」가 정직한 산출이고, 추정을 지어내지 않는다.

### 3-4. 단계별 배치 형태

| 단계 | 배치 | 이유 |
|---|---|---|
| **입력 이전** (`개념`·`인출`) | **몰기** — 연속 블록, 강의·개념 정리 | 재료를 넣는 단계. 전환비용이 가장 크다 |
| **초기** (`기준혼동`) | **몰기** + 인출은 매일 Anki | 절차를 세우는 단계. 우뢰 판정의 「초반 숙련도」가 여기 |
| **중기** (`미숙련`) | **몰기 + 분산 병행** — 메인은 묶고 문항은 쪼갠다 | 손이 따라와야 하므로 빈도가 약이 되기 시작 |
| **후기** (`실행실수`·`시간`) | **분산** — 빈도 ↑, 짧게 자주 | 간격 효과. 속도·정확도만 남은 단계 |

전 과목 공통이다. 과목별 현행 추정은 §5 표에 둔다.
