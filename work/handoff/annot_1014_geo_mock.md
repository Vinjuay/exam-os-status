## 0. 우뢰가 말한 범례 (10-14 채팅)
- **빨간 볼펜 (문항 번호 밑)** = 이 변형 문항의 **수능완성 원본 문항**. 이승헌이 수능완성에서 직접 선별해 변형한 문항들.
  - 14회 머리 메모(빨강): 「수능완성 / 대응된 선별 수완 문항 ↑ / 예) 1-10은 1회 10번(?) / 수능완성 원본 문제(?)」.
  - 표기 두 종류: `N-M` 와 `Np`. `N-M`의 M이 전부 20 이하 → **수능완성 실전 모의고사 N회 M번**으로 읽힘(추정). `Np` = 수능완성 본문 p.N. 머리 메모 판독이 완전치 않으니 우뢰 확인 1회 필요.
- **형광펜** = 모르는 단어·내용.
- **메모지(맨 뒤)** = 기억 안 나는 내용 목록.
- 빨간 「중요」 = 우뢰가 문항 옆에 찍은 표시(기준 미상 — 묻지 않음).

### 6-1. 14회 문항별 서사
- **1** 설명문의 위치 단서(자오선 부근 / 해안 저지대 석호 / 고원) 밑줄 → 세계지도에 위경도선(0·30·60 / 120·180)을 직접 그어 격자 만들기 → 호수를 격자에 찍어 A·C 선택.
- **2** 단서어 밑줄(팔라즈·대추야자·관광) → (가)(나)(다)에 오·사·아랍 → 그래프 B A C.
- **3** 지명 밑줄(포토맥·허드슨·뉴잉글랜드) → B A C.
- **4** 「라틴 – 인종」이라 적고 → **D 규칙**(1등→2등 짝)을 우상단에 먼저 써 놓음 → 막대마다 자·우·브·콜 → 범례 인종 → ㄷ 「적도가 국토를」에서 위치 확인(형광펜 = 여기서 막힘).
- **5** 수확 면적 비율 → 「…기후로 추론」: 작물 조합으로 기후를 먼저 읽고 → 카·튀·이.
- **6** 두 그래프(생산량 비율 vs 재배 면적 비율) → (가) 옥 (나) 밀 → 대륙 A~D 기호.
- **7·11** 범례에 「수·풍·태」 → 지역 약자(AS·라Am / 서남·유·AS).
- **8** 선지 판단 전에 원칙 한 줄: 「외노자는 농촌보다 도시로 일하러 간다 → 3차 산업」(**E**).
- **9** (가)(나)(다)에 일·중·타 → 순이동률 음수 = 「일하러 나감」(**E**) → 그래프 세 개 구분.
- **10** 막대 위에 나라 약자 → ㄷ 수위 도시 위도 비교에 「해발고도 영향」 메모(추론: 위도 말고 고도도 보라는 뜻).
- **12** 연교차·강수 편차 그래프 → A~D에 Cs·Af·Aw·Cfa(**A**) → 지도 점에도 같은 기호 → 보기 판단.
- **13** 질문표 열마다 뉴·런·몬·브 → ㄱ~ㄹ.
- **15** 지도 세 점에 기호(Aw/BS · Aw Bw · ET)(**A**) → 여백에 **B 표**(남 ET 5 / 남 BW 20 / 북 AW·BS 20) → 「7 0 △ 25」 로 차이 계산 → 하단에 **C 원칙** 적음. 이 문항이 B·C의 교과서.
